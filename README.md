### What I've built

**🤖 A multi-agent AI ecosystem in production**
A coordinator agent (**Vicky**) serves customers on WhatsApp (official Meta Cloud API) and on the web, and
delegates through **A2A** (agent-to-agent) to a team of expert agents — Tomy, Adam, Verónica, Danny, Dreams
and more — each one a specialist in a product. They all share the same blueprint: Python + LangGraph +
FastAPI, tracing in LangSmith, service-to-service authentication and cost guards.

**🧩 [Agent Hub](https://agentes.altaidigital.co)** — the platform that ties the ecosystem together
Multi-tenant: embeddable chat widget, WhatsApp, conversation history and leads, live human takeover,
credits and free trials, and a knowledge base with semantic search. Next.js + TypeScript + Prisma + PostgreSQL.

**🌙 [Encantamiento del Sueño](https://mayas.altaidigital.co)** — a 13-moon Mayan calendar app
A web app in three languages with accounts and sync, plus **Dreams**, an agent that guides personalized
readings in conversation. Calendar data comes from a deterministic engine, not from the model's memory, and
the code keeps track of each reading's progress. Payments with Polar.

**🌐 [Adam Network](https://adam.altaidigital.co)** — the platform where the Adam agent lives, with its own users, leads and commissions.

**📰 [Altai Content Hub](https://periodista.altaidigital.co)** — Altai's automated newsroom: news, campaigns and multi-channel publishing.

**🌐 [altaidigital.co](https://www.altaidigital.co)** — the company website (Next.js + Prisma).

### How I work
- **Local first:** every change lives in git before it reaches a server.
- **Verifiable deploys:** each deploy checks by hash that the server matches the commit exactly, and keeps a
  rollback ready.
- **Security by design:** keys between services, usage limits, and secrets kept out of the code.
